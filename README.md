# 🌦️ Weather Forecast App

A responsive weather application built using React.js that displays current weather information for any city using the free Open-Meteo API.

### Features
- Search weather by city name
- Display temperature in Celsius
- Show weather conditions, humidity, and wind speed
- Responsive design for desktop and mobile

### Technologies Used
React.js, JavaScript, HTML, CSS, Open-Meteo API, Vite
